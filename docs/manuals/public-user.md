# Public User Manual

## Role purpose

Search and read **published** legislative records on the public portal.

## Portal access

- Home: `/portal`
- Search ordinances, resolutions, minutes, and published documents.
- Pagination applies to large result sets.

## What you will not see

Unpublished or internal documents return **404 Not Found** — not a permission error. This prevents information leakage about draft records.

## Authenticated public users

If your LGU assigns a public-user login, you may have bookmark or notification features — still limited to published content.

## Privacy

The portal displays only records the legislative body has explicitly published. For data privacy requests, contact the LGU DPO — not the software vendor.

## You do NOT

- Use the portal to access restricted session floor or voting features (separate staff roles required).
